# Until 서울대 클로즈드 베타 런칭 플랜 (2026-07-14)

목표: **실사용 학생 30명 · 재방문(세션 재개) 30% · 만족도 로그 평균 4+** 를 4주 안에.
전략: 한 번의 빅런칭이 아니라 단계 확장 — 문제 생기면 초대 코드만 바꿔 즉시 잠근다.

## 0단계 — 배포 직후 점검 (D-0, 반나절)
- [ ] `deploy/DEPLOY.md` 체크리스트 통과(healthz·uid 격리·KV 생존·베타 게이트)
- [ ] 랜딩 `APP_URL` 연결 + CTA 클릭 → 게이트 → 코드 입력 → 첫 초안 (핸드폰에서도)
- [ ] `UNTIL_BETA_CODE` 1차 코드 설정(예: `SNU-EARLY`), `UNTIL_GLOBAL_DAILY_DRAFTS=200`
- [ ] 피드백 루프: `python -m until.feedback` 읽는 법 확인(만족도·준비경고 통계)

## 1단계 — 내부 런칭 (D-0 ~ D-3, 친구 5명)
- 아는 사람 5명에게 1:1로 초대(코드 직접 전달). **과제 하나를 실제로 끝내는 것까지** 지켜보기.
- 각자에게 딱 3가지만 묻기: ① 어디서 막혔나 ② 초안이 '내 것'이 됐나 ③ 친구한테 권할 건가.
- 발견된 문제 수정 전엔 확장하지 않는다.

## 2단계 — 클로즈드 베타 (D-3 ~ D-14, 목표 30명)
초대 코드 기반이라 채널에 뿌려도 유입이 통제된다. 코드는 채널별로 다르게
(`SNU-ETA` / `SNU-KATALK` / `SNU-GEEK`) — **어느 채널이 실사용자를 데려오는지** 코드로 측정.

### 채널 (Rented → 랜딩으로 수렴)
| 채널 | 방법 | 주의 |
|---|---|---|
| 과·동아리 단톡 | 지인 경유로 공유(본인이 직접) | 가장 전환 높음. 먼저. |
| 에브리타임 | 자유/홍보 게시판 1회 포스팅 | 광고 신고 정책 주의 — '무료 베타·학생 프로젝트' 톤, 링크는 랜딩만 |
| 스누라이프 | 동일 | 동일 |
| 디스콰이엇/GeekNews | '오픈소스 + 경계선 설계' 각도로 메이커 글 | 개발자 피드백·기여자 유입용(사용자와 별개) |

### 게시글 초안 (에타/단톡용 — 다듬어 쓰기)
> 과제 초안 잡아주는 AI를 만들고 있는 학부생입니다. ChatGPT랑 다른 점 하나:
> **판단이 필요한 부분은 절대 대신 안 정합니다.** 자료 정리·구조·초안까지만 하고,
> 관점/논지 같은 건 "여기는 네가 정해야 함"이라고 비워서 돌려줘요. 답하면 내 말투로
> 완성해주고, 마감/분량/인용 점검까지. eTL 연동돼서 과제 자동으로 불러옵니다.
> 무료 베타 테스터 구해요(초대 코드: SNU-ETA) → [랜딩 링크]

### 운영 루틴 (주 2회, 15분)
- `python -m until.feedback` — 초안 수·만족도·준비경고 추이
- KV 대시보드에서 uid 수(=사용자 수) 확인
- 만족도 낮은 세션 패턴 → 수정 백로그로

## 3단계 — 확장 판단 (D-14+)
아래 둘 다 참이면 오픈 베타(코드 공개/제거), 아니면 원인 수정 후 반복:
- 재방문율 30%+ (KV `sess:` 프리픽스 uid 중 2회 이상 방문)
- "친구에게 권하겠다" 다수(1단계 질문 ③를 계속 수집)
