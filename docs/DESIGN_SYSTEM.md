# Until 제품 디자인 기준 — v2 "연습장 × 정제" (2026-08-08)

Until의 화면은 **종이 위의 잉크**다. 대학생 책상 위의 사물(연습장·형광펜·스티키·빨간펜)
에서 시각 언어를 가져오되, 실행은 편집 디자인의 규율로 한다. 사용자는 AI의 능력보다
지금 어떤 과제가 선택됐고, 무엇이 채워졌고, 무엇을 직접 판단해야 하는지를 먼저 안다.

## 제품 인상

- 종이 위에 잉크로 쓴 조용한 도구 — 따뜻하되 감상적이지 않게
- 화면의 주인공은 브랜드가 아니라 **과제명과 남은 시간(D-day)**
- 필요한 내용만: 홈 = 4요소(레터헤드·행동·탈출구·링크 한 줄), 초안 = 3요소(본문·결정·버튼)
- AI는 배경 처리 수단 — 프리필은 "추천이 채워져 있어요"처럼 상태로만 알린다

## 토큰 (until/webassets/app.css `:root`)

| 토큰 | 라이트 | 역할 |
|---|---|---|
| `--ink` | `#191813` | 글·버튼·강한 괘선. 다크에선 종이와 반전 |
| `--page` | `#faf9f5` | 종이 배경(+2% 노이즈 `body::before`) |
| `--warn` | `#c0301f` | 마감·경고 — 빨간펜. 남용 금지 |
| `--hl` | `#ffe95c` | 형광펜 한 획(`.hl`) — 화면당 1곳 |
| `--sticky` `--sticky2` | `#fff3ad` `#dcebfa` | 결정 색면(노랑/파랑 교차) |
| `--mono` | IBM Plex Mono | 숫자·날짜·라벨 전용, `tabular-nums` |
| `--sans` | Pretendard Variable | 본문·헤드라인(자간 −1~−3%) |

## 시각 규칙

- **괘선 2단계**: 잉크 실선(`--ink` 1px)은 레터헤드·원장 상단만, 나머지는 헤어라인(`--line`)
- **모서리 0** — 라운드 카드 금지. 구획은 여백과 선으로
- **그림자 금지**(페이지 컨테이너 제외), 그라데이션·회전·glow 금지
- **결정 = 스티키 색면**: 무광 단색 + 왼쪽 잉크 축 2px. 노랑·파랑 교차(`.sd`, `.decision`)
- **숫자·날짜·상태는 모노**: `D-1 · 17:00`, `2026-08-08`, `01` — 오른끝 정렬
- **버튼**: 잉크 블록, 텍스트 왼쪽 + `→` 오른끝(`justify-content:space-between`), 한 줄만
- 이모지·알약 pill·장식 아이콘·스톡 이미지 금지

## 문구 규칙

- 시스템이 사람을 호명하는 번역투 금지: "당신이 정할 것 — 2" ✗ →
  **"이 두 가지만 정하면 완성됩니다"** ✓ (남은 개수·끝나는 시점을 문장이 전달)
- 슬로건("결정은 당신 몫")은 소개 페이지에만, 작업 화면에서는 상태 문장만
- 처리 문구는 관찰 가능한 단계로: "과제 본문을 읽는 중" ✓ / "AI가 생각 중" ✗

## 정보 구조

홈의 기본 행동은 `미제출 + 마감 전 + 마감 임박순` 과제 하나의 즉시 해결(fast)이다.
필터는 기본값으로 내장하고 조절은 목록 화면에서. 간단 흐름의 화면 골격:

1. **홈**: 헤드라인(형광펜 1획) → primary 버튼 → 밑줄 링크 → 양끝 정렬 링크 한 줄
2. **초안(/sv)**: 레터헤드(과제명 · D-day 빨강) → 본문(박스 없이 잉크선 아래) →
   "이 N가지만 정하면 완성됩니다" → 스티키 결정 폼 → 완성하기
3. **완성본(/svf)**: 레터헤드 → 본문 → 복사·다운로드(.docx/.pdf/.md/.html) → 남은 항목
