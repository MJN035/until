# 자료구조 프로그래밍 과제 2 — 코드 구현

과제: 파이썬으로 아래 함수를 구현하라. 알고리즘을 직접 코딩하고 소스 코드를 제출한다.

요구사항:
1. `def merge_sort(arr: list) -> list:` 병합 정렬 함수를 구현하시오.
   - 재귀로 분할하고 정렬된 두 리스트를 병합할 것.
   - 입력을 변경하지 말고 새 리스트를 반환할 것.
2. `def binary_search(arr: list, target) -> int:` 정렬된 리스트에서 target의
   인덱스를 이진 탐색으로 찾아 반환(없으면 -1)하는 함수를 구현하라.
3. 시간 복잡도를 주석으로 명시할 것.

제약: 표준 라이브러리 정렬(`sorted`, `list.sort`)을 쓰지 말 것. 파이썬 3.10+.
